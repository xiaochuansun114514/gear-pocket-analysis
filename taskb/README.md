# Task B — 齿轮辅助（花哥）系列外挂逆向取证

> 本目录记录对同一作者（By.羽霖咲华Unishua / 花哥）名下三款 Android 游戏外挂的逆向分析，用于**安全防御**。
> 三款应用共用同一套 iapp3（爱根）脚本引擎，仅身份常量不同，属同源软件。

| 应用 | 包名 | 版本 | 角色 |
|---|---|---|---|
| 齿轮辅助 | `com.huage.egaocl` | 11.1.0 | 主外挂（360加固 + beingyi 壳 + 云注入） |
| 冰糖雪梨 | `com.huage.pubgm.btxl` | 2.3.0 | 同源变体（硬编码口令 666） |
| 哔可防封 | `com.huage.pink.fangfeng` | 6.5.1 | 防封悬浮窗（木华云壳） |

## 样本包口令

```
infected
```

样本包使用 **AES-256**（pyzipper）加密，口令统一为 `infected`（恶意样本分析的通用口令）。
解压示例：`python -c "import pyzipper; pyzipper.AESZipFile('样本包_齿轮辅助系列_加密码.zip').extractall(pwd=b'infected')"`。
