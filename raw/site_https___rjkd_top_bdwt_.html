我们发布的软件都经过严格测试，不会包含任何病毒。

由于此类软件未进行备案，也不能上架应用商店，所以被手机厂商报毒属于正常情况。

【无法安装报毒软件】

（最简单的方法）

（用这个方法基本所有手机都可以）

安装软件的时候，请【关闭手机网络】，把 WiFi 和流量都关闭，再去安装软件，这样就可以。

下面也列出了部分手机报毒的解决方案。

小米 / 红米手机报毒解决办法

安装软件时，进入安装设置中，将【应用安全验证】和【安全守护】都关掉即可。

华为手机报毒解决办法

打开“手机管家” → “病毒查杀” → “风险管控中心”，选择该应用并点击“解除管控”。

再打开“设置” → “应用” → “权限管理”，修改权限设置即可。

切记：一定要先解除风控，再去开启软件权限。

OPPO / 一加手机报毒解决办法

进入手机设置 → 常规 / 其他设置 → 安全与隐私 → 允许安装未知源应用，打开开关即可。

VIVO / IQOO 手机报毒解决

进入手机设置，搜索“安全与隐私” → 更多安全设置 → 应用安装 → 禁止安装恶意应用，关闭开关即可。
